# 通用项目面试模板

这些模板仅用于用户没有提供项目背景时构造模拟场景。它们不是用户经历，也不代表某个真实系统。提问前应明确“下面使用通用模拟场景”，不得把模板中的技术或结果说成用户已经做过。

## RAG 知识问答系统

可选背景：面向公开文档或脱敏内部文档的检索增强问答系统。

可讨论链路：数据采集与清洗、切分、Embedding、向量检索或混合检索、Reranker、Query Rewrite、多轮上下文、Prompt、流式输出、评估和监控。

必须让候选人自行说明：实际数据来源、数据规模、模型与向量库、索引类型、TopK、Chunk 参数、评估集、质量指标、延迟和本人职责。模板不提供这些事实。

## Tool Calling / Agent 助手

可选背景：调用若干只读业务工具的助手，或带人工确认步骤的任务执行助手。

可讨论链路：Agent 与 Workflow 的选择、Tool Schema、参数校验、State 与 Memory、Human-in-the-loop、超时、重试、幂等、权限、审计和失败补偿。

若涉及外部系统写操作，默认要求人工确认、最小权限和可审计回执；不得假定候选人的项目已经实现这些机制。

## 文本分类系统

可选背景：对公开或已脱敏的短文本进行分类、分级或路由。

可讨论链路：标签设计、数据清洗、FastText/BERT 等模型对比、训练与验证、类别不平衡、阈值、Precision/Recall/F1、误报漏报成本、漂移和模型更新。

必须追问对照实验和业务成本，不能用“模型更先进”代替选型理由。

## 时间序列预测系统

可选背景：对公开或脱敏的能耗、流量、销量等序列预测未来数值。

可讨论链路：特征可用性、缺失与异常处理、时间窗口、训练验证测试的时间划分、简单基线、RNN/LSTM 或其他模型、单步与多步预测、MAE/RMSE、漂移和更新。

不得预设具体数据年限、特征、误差指标或上线收益。

## 通用追问顺序

先确认业务目标和个人职责，再追问链路、选型、替代方案、参数权衡、真实故障、优化、评估和生产化。遇到未提供的实现或指标，只能追问或标记待补充。
