# 个人知识库

把真实项目资料、复盘笔记和技术笔记以 Markdown 文件放在本目录。Skill 会按当前面试主题选择性读取相关文件，不会默认加载全部内容。

建议文件名：

- `rag.md`
- `agent.md`
- `langchain.md`
- `langgraph.md`
- `transformer.md`
- `bert.md`
- `machine-learning.md`
- `deep-learning.md`
- `my-rag-project.md`
- `my-agent-project.md`
- `interview-notes.md`

文件名不是硬性要求，但清晰的主题名有助于按需加载。一个文件尽量聚焦一个主题或项目。

## 推荐模板

```markdown
# 项目或主题名称

## 已确认事实
- 业务目标：
- 实际数据来源：
- 实际数据量：不知道就写“待补充”，不要估算
- 当前技术栈：
- 关键参数及选择原因：
- 已验证效果指标：

## 我负责的部分
- （填写本人真实负责内容）

## 遇到的问题与处理
- 问题：
  - 原因：
  - 处理：
  - 结果：

## 容易被追问的点
- （填写待复习或需补充证据的内容）
```

项目事实应写真实实现；无法确认的内容标记为“待补充”。技术原理笔记若与通用原理冲突，面试官仍会指出错误。

## 隐私提示

准备公开仓库时，不要提交客户信息、公司内部架构、内网地址、密钥、真实敏感指标或受保密协议约束的材料。可以把私有文件放到 `knowledge/private/`，该目录已被仓库根目录的 `.gitignore` 忽略。
